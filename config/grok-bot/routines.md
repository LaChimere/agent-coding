# Optional engineering routine templates

These are prompts to adapt to an authorized project, not active routines. First run the workflow
once, inspect results and use shadow mode for uncertain decisions. Fill in real sources, target,
freshness, task identity, time zone, limits and permissions before asking a host to schedule it.
The installed engineering package owns methods; use its continuous-work reference.

## Reproduce reported problems

Observe the agreed issue or error source using the narrow matching rule for this project.
Check source freshness and the affected release/commit. Group duplicate reports and locate any
existing active investigation before starting work. Reproduce through the project's verification
skill in the approved environment. Return the attempted route, actual result, build identity and
evidence. A confirmed issue may enter repair only within the agreed action scope. Report missing
data or prerequisites rather than treating them as a healthy result. Do not post to the source
system or enable a release unless that action is authorized.

## Observe an authorized release

For the named deployed build, compare the agreed health and user-behavior signals with the
baseline for the observation window. Verify the release is actually running. Notify on a material
change, failure, completion or decision; stay quiet while unchanged unless periodic reports were
requested. Follow the explicit pause/recovery conditions and authority. When an operation times
out, inspect the real release state before retrying or creating another rollback task.

## Maintain verification and prevent recurrence

Inspect recent project changes and the agreed verification map. Use maintain-verification-skill
to distinguish documentation drift, harness gaps and product regression. Preserve evidence and
report incomplete feature coverage. Group real repeated engineering mistakes and use
prevent-recurring-mistakes within the authorized scope, proving enforcement against the prior
failure and a valid control. No changes are needed merely to make a routine appear productive.
